# Device studio prototype
Operate mode. Average Linux gamer. Explore overview and device-specific capabilities with illustrative local data, no hardware bridge. English default, Russian selectable. Ready-made LCD themes and layer editing have equal access. Unsupported-device examples are explicitly demo-only.

## Direction contract
THESIS: Device-first gaming studio; screens are an optional capability, never the application shell.
OWN-WORLD: Graphite workbench, pale neutral text, lilac action accent, RGB restricted to hardware schematics and preview. Precise compact controls, generous central workspace.
STORY: Discover devices, select one, adjust a supported capability, distinguish draft from applied simulation.
FIRST VIEWPORT: Left device navigation, large overview heading, two unequal device rows with geometric hardware diagrams and capability links. Studio: central preview/diagram, right inspector, bottom draft bar. Signature interaction: selecting a light color updates the matching hardware zones, while Apply commits a separate local snapshot. Short panel reveal, no perpetual UI motion.
FORM: Peripheral configuration studio, grounded candidate 1, seed 54f8ad9a; user-selected and corrected to multi-device scope.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
