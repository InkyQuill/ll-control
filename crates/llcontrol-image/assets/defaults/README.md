`orbit-mark.png`: transparent two-orbit mark for image/watermark use.
`midnight.png`: opaque dark teal/violet background for readable sensor overlays.
Both are 480×480 RGBA PNG, generated reproducibly by
`tools/generate-lcd-defaults.py` using only Python's standard library.

These are original Linux defaults, not LIAN LI logos or copied Windows assets.
Stable versioned keys refer to immutable embedded bytes. Visual equivalence
with Windows defaults is not claimed. Builtin video and gallery contexts remain
separate roadmap work.
