# Матрица функций Galahad II LCDV2 в L-Connect 3 2.1.28

Дата исследования: 2026-09-08. Целевое устройство: Galahad II LCDV2,
USB `0416:7395`. Матрица описывает пользовательские сценарии Windows
L-Connect 3 `2.1.28.0`, а не все возможности общих enum или соседних моделей.
Исходное исследование M0 не выполняло аппаратных команд. Статусы дополнены
результатами [M1](../protocol/captures/2026-09-08-lcdv2-m1.md) 2026-09-08 и
сверкой M2/M3/M4 software и desktop 2026-10-12. Новых hardware runs при этой сверке не было.
Текущий backlog — [gaps](lcdv2-baseline-gaps.md).

Ссылки вида `UI Foo.cs:10` относятся к указанному reference root. Они
привязаны к этим хешам: повторная декомпиляция может изменить номера строк.
`Core RequestType.cs:5-18` перечисляет запросы именно Galahad2Vision, а
`Core SettingType.cs:5-12` — сохраняемые настройки. Наличие элемента в этих
enum само по себе не повышает статус строки.

Статусы используются буквально: `absent` — сценария нет в Linux;
`researched` — Windows-путь и применимость подтверждены, реализации Linux нет;
`codec-tested` — проверен только codec; `integration-tested` — проверен путь
между компонентами без нового осмотра физического LCD; `hardware-verified` —
есть физическое наблюдение; `not-applicable` — есть явное основание исключить
сценарий; `applicability-unknown` — caller или guard пока не установлен.
`partial` — часть пользовательского сценария реализована, остаток указан явно.
Для CLI/daemon результаты не подразумевают готовый GUI.
Историческое hardware evidence помечено отдельно и не является прогоном M0.

Сокращения источников: `UI` — `L-Connect 3/LConnect3cs/Products/Galahad2Vision/`;
`Svc` — `L-Connect-Service/LConnectService/Products/Galahad2Vision/`;
`Core` — `L-Connect.Core/LConnectCore/Products/Galahad2Vision/`.

## Покрытие и границы вывода

Подтверждённый product namespace напрямую даёт экранные эффекты, встроенную
композицию media + sensors/time/text/watermark, восемь screen profile slots
(`Galahad2VisionProfile.cs:27,53-65`), fan/pump control и оба RGB target.
Это требования parity даже там, где browser templates или фирменные assets
нельзя переносить буквально.

Общий WMSQ `Gallery`, встроенный в Galahad2Vision ImageVideo page, является
подтверждённым caller `L-Connect Editor.exe`: image crop/edit, video cut/edit,
MP4/GIF autofill, screen capture и screen record применимы. Фильтры импорта
точно ограничены PNG/JPG/JPEG, GIF и MP4 (`Gallery.cs:946-1027`), максимум —
35 файлов каждого типа (`:51-65,349-379`). В то же время
`ScreenAnimationEditorHelper.cs:16-25,79-82` принимает только
`HydroShiftIIOLEDCurve`, а единственный найденный caller находится в этом
product namespace. Поэтому отдельный Screen Animation Editor не входит в
LCDV2 baseline (`not-applicable` по подтверждённому product guard); это не
исключает обычный GA2LCD video editor из LCD-009/LCD-011.

Browser composition также привязана к продукту: service открывает
`Path.Combine(LConnectApp.Path.AssetsWMSQDirectory, "index.html")` в окне
480×480 (`Galahad2VisionController.cs:1088-1107`), а
`LConnectApp.cs:373` направляет WMSQ assets в `Assets/ga2v`. Cmd 15/offline
content остаётся неизвестным до нахождения caller. Общие функции других
LCD-моделей не добавлялись.

Ни `codec-tested`, ни успешная USB-запись не означают видимого эффекта.
M1 подтвердил физические JPEG и diagnostic H.264 на FW1.6. Это не закрывает
GIF/video workflow, аппаратный вывод новых theme compositions, все положения rotation или полный lifecycle.
Непроверенные сценарии перечислены в hardware acceptance; USB reconnect
отложен пользователем, suspend/cold boot остаются за пределами этого прогона.
